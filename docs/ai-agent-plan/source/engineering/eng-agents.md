## C1 Workflow and agent

Yazı önceden tanımlanmış kod yollarına sahip workflow ile modelin süreç ve araç kullanımını yönettiği agent'ı ayırır. Basit ve birleştirilebilir desenlerden başlayıp ihtiyaçla karmaşıklık ekleme yaklaşımı anlatılır.

## C2 Pattern selection

Routing, paralelleştirme ve orchestrator worker desenleri farklı görev yapılarına hizmet eder. Araç arayüzlerinin anlaşılır olması ve başarının değerlendirilmesi önemlidir. Sayfa eski tooling anlatımının güncel API kaynağı olmadığını belirtir.
