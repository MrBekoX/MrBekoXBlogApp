## C1 Context selection

Yazı agent çalışırken hangi bilgilerin sınırlı bağlamda tutulacağına odaklanır. İlgili bilgiyi gerektiğinde getirme ve gereksiz tool çıktısını azaltma, uzun görevlerde bağlam yönetimi için ele alınır.

## C2 Structured notes

Compaction ve yapılandırılmış not tutma, uzun çalışmalarda kararların ve çözülemeyen işlerin korunmasına yardımcı olur. Özetleme sırasında önemli ayrıntılar kaybolabileceğinden özet kalitesi gerçek agent izleriyle değerlendirilmelidir.
