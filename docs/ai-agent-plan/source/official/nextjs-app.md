Next.js App Router dosya sistemi tabanlı yönlendirme kullanır. React Server Components, Suspense ve Server Functions gibi özelliklerle bütünleşir. Sayfa ve layout yapısı App Router belge ağacında açıklanır.

## C2 Versioned implementation

App Router belgeleri backend ve istemci bileşenlerinin sınırlarını anlamak için başlangıç sağlar. Uygulamada kullanılacak route, veri erişimi ve etkileşim API'leri kurulu Next.js sürümünün ilgili belge bölümünden doğrulanmalıdır.
